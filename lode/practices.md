# Practices

- **Lode Coding**: Persistent project memory is managed in the `lode/` directory. All significant architectural decisions, domain language, and system states must be documented here.
- **AI Ownership**: The Lode is primarily written by and for the AI agent to maintain context across sessions.
- **Code is Truth**: If Lode content contradicts actual code, prioritize the code as the source of truth and update the Lode to match.
